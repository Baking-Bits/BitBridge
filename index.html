Admin features (device management and password reset) are available via Admin Login and will expand over upcoming builds.

Troubleshooting

  1. Choose the port that says USB Serial.
  2. If install stalls, hold BOOT while starting install, then release when flashing begins.
  3. Try both USB ports on dual-port boards.
  4. Try a different USB data cable.
